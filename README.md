🇯🇵 Japan Earthquake Data Analysis Dashboard (日本地震データ分析ダッシュボード)
An interactive Power BI dashboard analyzing seismic activity and earthquake distributions across Japan from 2019 to 2021.
Designed with a focus on minimalist aesthetics, bilingual data labeling (English & Japanese), and clear safety severity tiers.

📊 Dashboard Overview: 
Total Recorded Earthquakes (総地震発生回数): ~2,000 events tracked and mapped.Highest Recorded Magnitude (最大地震規模): $M 7.10$ max impact threshold.Recording Period (記録期間): 2019 – 2021

Key Features:Geospatial cluster mapping of seismic activity centers.Dynamic Magnitude Slicer (規模フィルター) for interactive exploration.Clean layout structured for rapid visual comprehension (Bōsai / disaster preparedness context).

🛠️ Tools & Technologies UsedPower BI Desktop (Data Modeling, DAX Measures, Map Visualizations,
DAX (Custom string measures for dynamic time ranges and aggregations)

Dataset: Historical earthquake logs (2019–2021)

🚀 How to View/Run
Download the .pbix file from this repository.
Open it using Power BI Desktop.
Explore the interactive filters and map clusters.
